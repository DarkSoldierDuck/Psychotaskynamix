# 《飘》—— 关于解离体验的互动短篇
# 命令: bg 名称 | float 0~1 | time 时间戳 | title 标题 | label 名 | jump 名 | choice 选项1->label|选项2->label | hold 提示文本 | end
# 对话: 说话人：文本 ；无冒号行为旁白

title 飘 —— 一段关于解离的互动短篇

bg classroom
time 14:37
# ===== 第一章 日常里的缝 =====

label ch1
旁白：下午的教室，阳光斜着切进来，把一半的课桌染成暖色。
旁白：笔记本摊开在面前，笔尖停在半空。
我：刚才讲到哪了？
旁白：……第几页来着。这一页的字迹很陌生，虽然分明是自己的笔迹。
旁白：抬头。黑板上的板书只写了一半，粉笔灰还没落定。
同桌：喂，发什么呆呢。
choice 看笔记->c1_note|看黑板->c1_board

label c1_note
我：……这条公式是什么时候写的？
同桌：十分钟前你自己写的啊。
label c1_board
旁白：十分钟。黑板上的字是我的字。
旁白：可我对「写下它」这件事，没有任何感觉。

旁白：放学路上，我数着地砖的缝。一、二、三……
旁白：数着数着，忽然发现自己站在小卖部门口。
旁白：中间那一段路，是空的。
我：（我记得的最后一件事，是在数第 37 块砖。）
time 16:52
旁白：手机上的时间，和记忆里的位置，对不上了。

# ===== 第二章 飘 =====

label ch2
bg corridor
float 0.6
time 次日 09:15
title 第二章 飘
旁白：第二天早自习，那种感觉又来了。
旁白：先是声音变远，像隔了一层水。
旁白：然后是身体——手放在桌面上，却像是在很远的地方看着这只手。
我：（我在这吗？）
旁白：走廊尽头有人在笑，笑声传过来时已经不像是声音了。
choice 试着抓住桌沿->c2_hold|什么都不做->c2_nothing

label c2_hold
旁白：指尖碰到桌沿。硬的、凉的。
旁白：有这一点点真实，就够了。
旁白：世界稍微回来了一点。只是稍微。

label c2_nothing
旁白：我什么都没做。
旁白：飘着其实……也不坏。很安静。没有人声，没有要求。
旁白：像退到很远很远的地方，看水面上发生的一切。
float 0.8
旁白：可我知道，飘得太远，就很难自己回来了。

旁白：晚上，朋友发来消息。
小原：你今天课上是不是不太舒服？看你一直没什么反应。
choice 我没事->c2_fine|不知道怎么说->c2_unknown

label c2_fine
我：我没事。
旁白：发出去之后，盯着这四个字看了很久。
旁白：我也不知道这是不是真的。
jump c2_merge

label c2_unknown
我：不知道该怎么说。
小原：那就不用说。明天我坐你旁边。
label c2_merge

bg corridor
time 21:40
旁白：睡前整理书包。第二天的课本、眼镜……
旁白：眼镜。眼镜放哪了？
旁白：二十分钟前我还拿着它。现在，整个房间都找不到。
旁白：我不是忘了放在哪——是「放」这个动作本身，没有留在我这里。

# ===== 第三章 接地 =====

label ch3
bg classroom
float 0.35
time 第三天 12:05
title 第三章 接地
旁白：中午的天台，风很大。小原把我叫了出来。
小原：你最近，是不是常常「不在」？
choice 什么事都不在？->c3_q|嗯。->c3_yes

label c3_q
我：什么事都不在？
小原：就是……人在，但你在别的地方。
label c3_yes
小原：我没法替你把那些时间找回来。
小原：但你要不要试试——有东西拉着你的时候，就别松手。

旁白：风把这句话吹得摇晃。
float 0.7
旁白：又是那种感觉。声音先退潮，然后是眼前的一切。
旁白：视野的边缘开始发灰，像相纸泡进了显影液的反面。
我：（又来了。这次……可能比上次更远。）
旁白：小原还在说话，但声音已经隔了很厚的一层。
小原：——喂。听得见吗？
choice 试着回答->c3_talk|说不出话->c3_silent

label c3_talk
我：……听得见。
label c3_silent
旁白：喉咙里没有声音。但我抬起手，碰了碰小原的手腕。
label c3_after
小原：好。那，过来。
hold 抱住小原
旁白：呼吸慢下来。心跳慢下来。
旁白：灰色的边缘，一寸一寸退了回去。
float 0
旁白：风还是风，天台还是天台。但「我在这里」这件事，重新有了重量。
我：……好像，看得进去了。
小原：嗯。
小原：下次飘走之前，先喊我。喊不到，就摸摸这里——校服袖口，我缝了个结。
旁白：不是治愈。以后它还会来，像天气一样。
旁白：但天气预报是可以有的。伞也是可以有的。
小原：走了走了，下午的课要迟到了。
我：（今天下午的时间，我想自己留着。）
