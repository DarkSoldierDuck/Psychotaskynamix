# 心理作业

本仓库存放心理课程的作业与创作。

## 目录

- `OSDD-Galgame/` — Unity 文字冒险游戏《飘》：以互动机制呈现解离体验（记忆断层、时间空洞、"飘离"感、接地）。含完整 Unity 工程源码、三章剧本、程序化生成的水彩风背景。
- `说明.txt` — 游戏设计说明与运行方法。
- `work.py` / `星图.py` / `描述.txt` / `智力.png` — 之前的心理作业：用 Python 生成的"智力星图"。

## 《飘》简介

第一人称 galgame，约 10 分钟流程。玩家通过对话推进感受解离状态下"人在但不在"的体验：背景逐渐灰度化、文字褪色闪烁、时间戳悄悄跳变、选项在飘离严重时变灰无法点击。结尾的长按交互（接地）是唯一能拉回现实的方式——不是"选对答案"，而是一个具体的、物理的、需要持续的动作。

剧情、人物、对话均为虚构创作，不对应任何真实个人。
